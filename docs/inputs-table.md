# 입력 요소 전수 표 (WP2-3·2-4)

필수는 원리 측정에 꼭 필요한 최소(오늘 공부할 내용·사전 응답·사후 응답과 자기설명·되짚기 서술 1개)로 줄였다. 한 차시(class40) 기준이다. 자세히(full) 모드는 연구용 기존 동작을 유지한다.
건너뛴 선택 항목은 `session.skipped`에 기록되고 점수 계산에서 0이 아니라 제외(null)된다. 교사 CSV에는 `skipped` 열이 있다.

| 화면 | 입력 | 개선 전 | 개선 후(한 차시) | 칩·음성으로 대체 | 근거 |
|---|---|---|---|---|---|
| 시작 | 오늘 공부하고 싶은 것 | 필수(서술) | **필수** — 예시 문장 칩 3개, 넓으면 2~3개로 좁혀 고르기 | ✓ 칩 | 전문가1 |
| 시작 | AI와 할 일 나누기 | 선택(기본값) | 선택 — 프리셋 3종 | ✓ 프리셋 | 전문가2·4 |
| 아는 것 확인 | 사전 문항 | 필수 4문항(선다 2+서술 2) | **필수 2문항(선다 1+서술 1)** | ✓ 선다·🎤 | 전문가3·4·5, 원리13 동수 |
| 아는 것 확인 | 자신감 | 필수(그림 버튼) | 필수(그림 버튼) | ✓ 버튼 | 원리6 |
| 스스로 점검 | 평소 공부법 + 이해·전략·연결 | 필수 서술 4턴 | **필수 고르기 4줄(칩) + 선택 한 줄** | ✓ 칩 | 전문가2·5, 원리7 구별 유지 |
| 방법 고르기 | 공부 방법 | 필수(카드) | 필수(카드) | ✓ 카드 | 원리8 |
| 방법 고르기 | 고른 까닭 | 필수 서술 | 필수 — **까닭 칩 4개 + 직접 쓰기** | ✓ 칩 | 전문가7(추궁형), 원리8 |
| 해 보기 | 대화 | 서술 | 서술 + 🎤(한국어) + 수식 기호·풀이 단계 | ✓ 🎤 | 전문가2·3·4·6 |
| 해 보기 | 이해도 체크포인트 이유 | 필수 서술 | **칩 1번 또는 선택 서술** | ✓ 칩 | 전문가4 |
| 해 보기 | 막혔어요 | 바로 AI 응답 | 도움 종류 3지선다 | ✓ 칩 | 전문가1 |
| 돌아보기 | 내 말 표시(가) | 필수(1개 이상) | **선택** | ✓ 버튼 | 전문가5 |
| 돌아보기 | 역할 되돌아보기 글(가) | 필수 | **선택** | ✓ 문장 틀·🎤 | 전문가2·5 |
| 돌아보기 | 질문 고르고 점수(나) | 필수 | **선택** | ✓ 버튼 | 전문가5 |
| 돌아보기 | 돌아보며 적기(나) | 필수 | **필수 1개** | ✓ 문장 틀·🎤 | 원리11·12 |
| 돌아보기 | 다음엔 이렇게 / 더 궁금한 것 | 없음 | 선택(신규) | ✓ 칩 | 전문가5·7 |
| 혼자 풀어보기 | 사후 문항 풀이 | 필수 4문항 | **필수 2문항(사전과 같은 수)** | ✓ 선다·🎤·수식 | 원리13 |
| 혼자 풀어보기 | 자기설명 | 짝지은 문항 필수 | 같음 | ✓ 🎤 | 원리13 |
| 혼자 풀어보기 | 마지막 글 | 필수 | 필수 | ✓ 문장 틀·🎤 | 원리13 |

- 서술이 필요한 단계 18개 중 칩·음성으로 대체할 수 있는 단계는 18개다(100%, 수용 기준 80% 이상).
- 필수 입력 수(한 차시): 14 → 9.
- 시범 운용 계측(16회 평균): 학생이 친 글자 504 → 308자(−39%), 누른 횟수 68.5 → 48.9회.
