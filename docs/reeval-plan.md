# 재평가 설계 (WP6-3)

## 대상과 판
- 기존 전문가 7인(같은 27문항·4점 척도, 정성 Q1~Q3) + 학생 소규모(학년군별 4~6명: 초3~4, 초5~6, 중)
- 평가할 판: 이번 개선 커밋을 배포한 주소 **하나만** 안내하고, 안내문에 배포 커밋 해시를 적는다(지난번처럼 평가 주소와 README 주소가 달라지지 않게, `docs/repro.md` WP0-1).
- 수업 방식: 교사 화면 [2-1 수업 운영 점검]의 **한 차시(40분) 링크**(`/?mode=class40`)를 기본으로 한다. 자세히 모드는 연구용으로 따로 평가한다.

## 과제 시나리오(평가자·학생 공통)
1. 처음 가입: 그림 비밀번호 두 번 확인 → 비밀번호 카드 → 둘러보기 6장 → [연습해 보기]
2. 실제 공부 한 번(과목은 국어·수학·사회·과학 중 1개, 수학은 풀이 단계 쓰기 포함, 과학은 남중 고도 단원 권장)
3. 도중에 [내 진단 보기], [막혔어요] → 도움 종류 고르기, [한 단계 더 도와주세요] 한 번
4. 돌아보기 → 혼자 풀어보기 → 내 공부방 "이번 공부 한눈에"
5. 교사: 수업 운영 점검(소요시간·오류 신고·채점 근거) 확인

## 수집 항목
- 27문항 점수·정성 의견, `phaseTimes`(단계별 분), 교사 CSV(`flag_*`, `error_reports`, `skipped`, `help_requests`, `meta_level_*`)
- 학생 오류 신고 원문, 스스로 점검 "이상해요" 신고 수
- 🔶 전문가3에게 남중 고도 오류가 나온 화면·문장을 받아 `tests/fixtures/science-namjung.json`의 `reported`에 넣는다.
