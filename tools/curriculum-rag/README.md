# 교육과정 원문 RAG 색인

## 왜 필요한가
`curriculum_standards.js`의 성취기준 1,491개 가운데 약 40%는 해설이 없다(문장 하나뿐, 평균 해설 길이 140자). 전문가3이 지적한 **남중 고도 설명 오류**는 해설이 비어 있는 `6과13-01`(태양 고도·그림자 길이)·`6과13-02`(남중 고도와 낮의 길이)에서 나왔다. 모델이 기댈 근거가 없는 곳이다.
교육부 고시 원문(별책)에는 성취기준 문장 외에도 단원명, 탐구 활동, **(가) 성취기준 해설**, **(나) 성취기준 적용 시 고려 사항**, 내용 체계(핵심 아이디어·지식·이해·과정·기능·가치·태도), 교수·학습과 평가 방법이 있다. 이것을 조각내 색인하고 대화에 근거로 넣는다.

## 쓰는 곳
| 기능 | 원문 쓰임 |
|---|---|
| 대화 시스템 프롬프트 | 지금 대화와 가장 가까운 조각 4개를 출처와 함께 넣고, "원문에 없는 사실은 지어내지 말 것"을 지시 |
| 사실 검수(WP3-3) | 사실 진술 문장을 원문 근거와 대조(temperature 0). 틀리면 재생성하고, 그래도 틀리면 확인을 권하는 말로 바꿈 |
| 진단 문항 출제 | 출제 범위에 원문 근거를 함께 줌 |
| 대표 오개념(WP3-2) | 원문 범위 안에서만 생성 |
| 자료 카드(WP3-5) | 원문 조각을 150자 이내로 **그대로** 보여 줌(새 사실을 만들지 않음) + 출처·쪽 |
| 근거 자료 창(원리10) | 원문 조각과 별책·쪽 표시 |
| 교사 오류 신고 목록 | 그 AI 응답이 참고한 원문 조각 표시 |

검색은 브라우저 안 BM25(낱말 + 한글 2글자 묶음)로 한다. 외부 임베딩 API를 쓰지 않으므로 비용·지연·개인정보 전송이 없다. 지금 공부하는 성취기준의 원문에 가산점을 준다.

## 색인 만들기
```bash
# 1) PDF → 쪽 번호가 붙은 텍스트 (pdfjs-dist는 개발용 — 저장소 의존성에 넣지 않음)
npm i --no-save pdfjs-dist@4.10.38
node tools/curriculum-rag/extract-pdf.mjs <별책.pdf> <폴더>/sci.json
echo '{"title":"교육부 고시 제2022-33호 [별책 9] 과학과 교육과정"}' > <폴더>/sci.meta.json
# 2) 색인(원문이 없는 과목·학년군은 curriculum_standards.js로 채움)
npm run rag:build -- --pdf-json <폴더>
```
결과는 `data/rag/<학년군>__<과목>.json`(학년군: e34·e56·m·h1)과 `manifest.json`이다.

## 현재 색인에 들어간 원문(2026-10-30)
| 원문 | 쪽 | 조각 | 출처 |
|---|---|---|---|
| 교육부 고시 제2022-33호 [별책 9] 과학과 교육과정 | 292 | 1,730 | 교과서 출판사 자료실(비바샘) 공개본 |
| 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정(초등) | 42 | 378 | 교과서 출판사 자료실(비바샘) 공개본 |
| 나머지(국어·사회·영어, 중·고 수학 등) | – | – | `curriculum_standards.js`(성취기준 + 있는 해설) |

🔶 **연구진 준비물**: 국어(별책 5)·사회(별책 7)·영어(별책 14)·수학 중고등 별책과, 교육부가 펴낸 **교과별 교육과정 해설서** PDF를 국가교육과정정보센터(ncic.re.kr)에서 받아 위 절차로 넣으면 그 과목도 원문 근거로 바뀐다. 해설서처럼 성취기준 코드가 본문에 섞인 문서는 `원문` 조각으로 들어가고, 조각 안의 코드로 성취기준에 연결된다.

고시문은 저작권법 제7조(보호받지 못하는 저작물)에 해당한다. 출판사 재편집본을 쓴 경우 쪽 머리말 등 출판사 문구는 색인에서 지운다(`NOISE` 규칙). 원본 PDF는 저장소에 넣지 않는다.

## 알려진 한계
- PDF 줄바꿈 때문에 끊긴 낱말은 문서 안 낱말 사전으로 되붙인다. "가치⋅태 도"처럼 가운뎃점이 낀 낱말은 일부 남는다(검색은 2글자 묶음이라 영향이 작다).
- 표로 된 내용 체계는 칸 순서가 섞인 텍스트로 들어간다. 검색 근거로는 쓸 수 있지만 그대로 보여 주기에는 거칠다.
