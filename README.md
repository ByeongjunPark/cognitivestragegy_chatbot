# 초중등 메타인지 & 인간-AI 상호작용 성찰 대화형 AI 챗봇 (CognitiveStrategy Chatbot)

본 프로젝트는 **초중등 학습자의 메타인지 능력 신장**과 **인간-AI 간 협력적 성찰 역량 함양**을 목표로 연구·도출된 **13대 교육공학적 설계원리**를 구현한 대화형 AI 튜터 시스템 프로토타입입니다.

Upstage의 최신 초거대 언어모델(**Solar Pro**)을 기반으로 구동되며, 대화 준비부터 과정, 종결 및 AI 소거 전이 과업까지 체계적인 자기조절학습(Self-Regulated Learning) 사이클을 지원합니다.

## 🔑 Upstage API 키 설정 방법 (가장 쉬운 안내)

프로젝트 폴더 내의 **`.env` 파일**을 메모장이나 VS Code 등의 텍스트 편집기로 열어 발급받으신 API 키를 입력하시면 됩니다.

### 1단계: `.env` 파일 열기
프로젝트 최상위 폴더에 있는 `.env` 파일을 엽니다. (만약 보이지 않는다면 `.env.example` 파일을 복사하여 파일명을 `.env`로 변경하세요.)

### 2단계: API 키 입력 및 저장
```env
# Upstage 개발자 콘솔 (https://console.upstage.ai/)에서 발급받은 API 키
UPSTAGE_API_KEY=여기에_발급받으신_키를_붙여넣으세요

# 모델 설정 (기본: solar-pro)
UPSTAGE_MODEL=solar-pro
UPSTAGE_BASE_URL=https://api.upstage.ai/v1
UPSTAGE_REASONING_EFFORT=medium
```
> [!IMPORTANT]
> - `.env` 파일은 `.gitignore`에 등록되어 있어 **GitHub 공개 저장소에 푸시해도 절대 유출되지 않도록 안전하게 보호**됩니다.
> - 소스 코드 내부를 수정할 필요 없이 오직 `.env` 파일의 키 값만 입력/변경하시면 됩니다.

## 🏛️ 13대 교육공학적 설계원리 완벽 매핑

| 계열 | 원리 명칭 | 시스템 구현 기능 및 위치 |
| :--- | :--- | :--- |
| **시스템 공통 구현** | **1. 비계의 적응적 지원 감소 (Fading)** | 대화 턴수에 따라 `High`(구체적 비계) $\rightarrow$ `Medium` $\rightarrow$ `Low`(독립 탐구)로 힌트 수준 점진적 자동 감소 및 사이드바 수동 조절 기능 |
| | **2. 학습자 선택권 및 최종판단 보존** | AI가 정답/판단을 대신 내리지 않고 질문과 선택지를 던져 학습자 주도성을 보존하는 소크라테스식 프롬프트 엔지니어링 |
| | **3. 대화과정의 기록 및 시각화** | 개인정보(이름, 연락처 등) 자동 비식별화 필터링 및 전 과정 JSON/로그 데이터 내보내기 기능 |
| **대화 준비 단계 (학습 맥락 & 사전지식 점검)** | **4. 학습 목표 및 교과 맥락 설정** | 과목, 단원, 학습 목표, 구체적 과제를 입력받는 구조화된 입력 폼 (1단계 탭) |
| | **5. 학습자-AI 간 과업 분담 명확화** | 조력자/동료 탐구자/점검자 등 학습 목적에 따른 AI 역할 선택 메커니즘 |
| | **6. 교과 내용지식 사전 활성화 및 점검** | 사전 이해도 자가 평가 슬라이더(1~5점) 및 기존 지식 인출 입력란 |
| | **7. 메타인지적 지식 점검** | Kramarski & Mevarech 이론 기반 **이해 질문, 전략 질문, 연결 질문** 3대 사전 점검 질문 |
| **대화 과정 단계 (인지전략 조절 지원)** | **8. 인지 전략 계획 수립** | 시연, 정교화, 조직화, 비판적 사고, 이해 점검 중 학습자가 주도적으로 인지 전략 선택 및 선택 이유 명시 |
| | **9. 인지 전략 모니터링 기반 조정** | 대화 도중 이해 정체 시 사이드바에서 전략 변경 및 변경 사유 누적 기록 |
| | **10. AI 기반 응답 검증 및 수용 여부 판단** | 모든 AI 응답 카드 하단에 [수용 / 의문 / 수정필요] 판단 라디오 버튼 및 학습자 비판 코멘트 패널 제공 |
| **대화 종결 및 성찰 단계 (대화 이후)** | **11. 학습자-AI 간 역할 및 위임 성찰** | 학습자 주도 질문 vs 단순 AI 위임 질문 비율 파이차트 시각화 및 주도권 성찰 작성 |
| | **12. 상호작용 및 질문 궤적 성찰** | 학습자가 입력한 프롬프트 전체 타임라인 테이블 및 프롬프트 구체성·적절성 성찰 |
| | **13. 교과 지식 및 인지 전략 변화 성찰** | **AI 도움을 완전히 소거한 상태**에서 유사 수준의 전이 과업(Transfer Task)을 스스로 풀고, 사전 vs 사후 이해도 변화 비교 막대 그래프 제공 |

## 🚀 실행 방법

### 방법 1: 원클릭 배치 파일 실행 (가장 추천)
프로젝트 폴더 내의 **`run_chatbot.bat`** 파일을 더블 클릭하면 자동으로 환경을 감지하여 웹 브라우저가 실행됩니다.

### 방법 2: 명령 프롬프트(CMD / PowerShell) 실행
```bash
# 1. 의존성 패키지 설치
pip install -r requirements.txt

# 2. 스트림릿 애플리케이션 실행
streamlit run app.py
```

실행 후 웹 브라우저에서 `http://localhost:8501`로 접속됩니다.
