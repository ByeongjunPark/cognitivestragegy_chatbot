# 초중등 메타인지 & 인간-AI 상호작용 성찰 대화형 AI 챗봇 (CognitiveStrategy Chatbot)

본 프로젝트는 **초중등 학습자의 메타인지 능력 신장**과 **인간-AI 간 협력적 성찰 역량 함양**을 목표로 연구·도출된 **13대 교육공학적 설계원리**를 구현한 대화형 AI 튜터 시스템 프로토타입입니다.

Upstage의 최신 초거대 언어모델(**Solar Pro**)을 기반으로 구동되며, 대화 준비부터 과정, 종결 및 AI 소거 전이 과업까지 체계적인 자기조절학습(Self-Regulated Learning) 사이클을 지원합니다.

## 🔒 API 키 보안 안내 (중요)

이 시스템은 **API 키를 브라우저(index.html)에 절대 하드코딩하지 않습니다.** 대신:

1. **기본 동작(권장)**: 브라우저는 `/api/chat`이라는 자체 서버 프록시만 호출하고, 실제 Upstage API 키는 서버 환경변수(`UPSTAGE_API_KEY`)에만 보관됩니다. 이 방식은 Vercel처럼 서버리스 함수를 실행할 수 있는 호스팅에서만 동작합니다.
2. **개인 키 모드(선택)**: `/api/chat` 프록시가 없는 정적 호스팅(GitHub Pages 등)에서는 우측 상단 ⚙ 설정에서 학습자 본인의 Upstage API 키를 입력할 수 있습니다. 이 키는 **입력한 브라우저의 `localStorage`에만 저장**되며 절대 저장소(git)에 커밋되지 않습니다.

> [!WARNING]
> 과거 커밋에 테스트용 Upstage API 키가 실수로 하드코딩되어 공개 저장소에 노출된 적이 있습니다. 해당 키는 **Upstage 콘솔(https://console.upstage.ai/)에서 반드시 폐기·재발급**하시고, 새 키는 아래 방법대로 서버 환경변수 또는 `.env`(로컬 실행 시)에만 넣어주세요. 코드에 다시 하드코딩하지 마세요.

### Python(Streamlit) 로컬 실행용 `.env` 설정

```env
# Upstage 개발자 콘솔 (https://console.upstage.ai/)에서 발급받은 API 키
UPSTAGE_API_KEY=여기에_발급받으신_키를_붙여넣으세요

# 모델 설정 (기본: solar-pro)
UPSTAGE_MODEL=solar-pro
UPSTAGE_BASE_URL=https://api.upstage.ai/v1
UPSTAGE_REASONING_EFFORT=medium
```
> [!IMPORTANT]
> `.env` 파일은 `.gitignore`에 등록되어 있어 git에 커밋되지 않습니다. 소스 코드를 수정할 필요 없이 `.env` 값만 입력/변경하면 됩니다.

## ▲ Vercel 배포 (API 키 안전하게 보관하기, 권장)

`index.html` + `api/chat.js`(서버리스 프록시)를 함께 배포하면, 학습자는 아무 설정 없이 바로 사용할 수 있고 API 키는 서버에만 존재합니다.

```bash
# 1. Vercel 로그인 (최초 1회, 브라우저 인증)
vercel login

# 2. 프로젝트 루트에서 배포
vercel --prod

# 3. API 키를 Vercel 환경변수로 등록 (배포와 별개로 1회 설정)
vercel env add UPSTAGE_API_KEY production
# -> 프롬프트가 뜨면 Upstage 콘솔에서 발급받은 키 값을 입력

# 4. 환경변수 반영을 위해 재배포
vercel --prod
```

배포가 끝나면 `https://<프로젝트명>.vercel.app` 형태의 URL이 발급됩니다. 이 URL이 API 키가 노출되지 않는 **정식 서비스 주소**입니다.

## 🏛️ 13대 교육공학적 설계원리 완벽 매핑

| 계열 | 원리 명칭 | 시스템 구현 기능 및 위치 |
| :--- | :--- | :--- |
| **시스템 공통 구현** | **1. 비계의 적응적 지원 감소 (Fading)** | AI 응답을 3회 연속 "수용"으로 판단하면 `High → Medium → Low` 순으로 힌트 수준을 **자동으로 페이딩**(`applyAdaptiveFading`)하고 채팅창에 알림을 표시. 우측 패널의 수동 조절 버튼도 항상 열려 있어 원리2(학습자 선택권)를 해치지 않음 |
| | **2. 학습자 선택권 및 최종판단 보존** | 시스템 프롬프트에 "정답/이해도/전략의 옳고 그름을 AI가 대신 단정하지 말 것"을 명시적 규칙으로 고정. 전략 선택, 비계 조절, 응답 수용 여부 등 모든 최종 판단은 학습자의 클릭/입력으로만 확정됨 |
| | **3. 대화과정의 기록 및 시각화** | 전화번호/이메일/주민번호 패턴 자동 비식별화(`anonymize`), 대화·검증·성찰·전략기록을 포함한 전 과정 JSON 내보내기, 주도권 비율·이해도 성장 실시간 차트 |
| **대화 준비 단계 (학습 맥락 & 사전지식 점검)** | **4. 학습 목표 및 교과 맥락 설정** | 회원가입 시 학년(초3~고3)·교과목·교육과정 성취기준 선택 + 대화 시작 시 학습자 본인의 구체적 학습목표를 묻는 1단계 발문 |
| | **5. 학습자-AI 간 과업 분담 명확화** | 대화 준비 2단계: "오늘 AI에게 기대하는 역할(힌트 질문자/동료 탐구자/설명 점검자)"을 학습자가 직접 정하는 1개 질문 |
| | **6. 교과 내용지식 사전 활성화 및 점검** | 대화 준비 3단계: 사전 지식·경험 인출 + 5점 만점 자가 이해도 점수 입력(사전 이해도 차트에 반영) |
| | **7. 메타인지적 지식 점검** | Kramarski & Mevarech 이론에 따라 **이해질문 → 전략질문 → 연결질문** 3개를 별도의 순차 단계(원리7-①/②/③)로 각각 1개씩 질문 |
| **대화 과정 단계 (인지전략 조절 지원)** | **8. 인지 전략 계획 수립** | 준비 7단계: 우측에서 고른 인지 전략(시연/정교화/조직화/비판적 사고/이해 점검)에 대해 "왜 이 전략이 도움이 될지" 근거를 학습자가 직접 말하도록 유도하는 전용 질문, 근거는 전략 기록에 저장 |
| | **9. 인지 전략 모니터링 기반 조정** | 본 대화 중 "지금 전략이 잘 안 통해요" 버튼(`requestMonitoring`)을 누르면 AI가 점검 질문+대안 전략을 제안하고, 학습자가 전략을 변경할 때마다 사유를 입력받아 사이드바 "전략 선택·조정 사유 기록"에 누적 표시 |
| | **10. AI 기반 응답 검증 및 수용 여부 판단** | 모든 AI 응답 클릭 시 [수용 / 의문 / 수정필요] 판단 팝업 모달 + 비판적 코멘트 입력란 (원리1의 자동 페이딩 판단 근거로도 사용됨) |
| **대화 종결 및 성찰 단계 (대화 이후)** | **11. 학습자-AI 간 역할 및 위임 성찰** | 종결 직후 주도권 성찰 발문 + 주도적 탐구(🌟) vs AI 위임(🤖) 비율 파이차트 + **대화 로그 대시보드**에서 개별 질문을 선택해 역할 성찰 코멘트 작성 |
| | **12. 상호작용 및 질문 궤적 성찰** | 프롬프트 개선 발문 + 동일한 **대화 로그 대시보드**(전체 질문 타임라인)에서 각 질문을 선택해 "더 명확하게 개선한다면?" 코멘트 작성 |
| | **13. 교과 지식 및 인지 전략 변화 성찰** | 전이 과업 진입 시 비계를 `Low(소거)`로 자동 고정하고 수동 조절도 잠가 **AI 도움을 실제로 제거**한 상태에서 유사 전이 과업을 스스로 풀게 하고, 사전 vs 사후 이해도 비교 막대 그래프 제공 |

## 🚀 실행 방법

### 방법 1: 원클릭 배치 파일 실행 (가장 추천)
프로젝트 폴더 내의 **`run_chatbot.bat`** 파일을 더블 클릭하면 자동으로 환경을 감지하여 웹 브라우저가 실행됩니다.

### 방법 2: 명령 프롬프트(CMD / PowerShell) 실행
```bash
# 1. 의존성 패키지 설치
pip install -r requirements.txt

# 2. 스트림릿 애플리케이션 실행
streamlit run app.py
```

실행 후 웹 브라우저에서 `http://localhost:8501`로 접속됩니다.
