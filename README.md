# 메타인지·AI활용 성찰 지원 시스템 (CognitiveStrategy Chatbot)

본 프로젝트는 **초중등 학습자의 메타인지 능력 신장**과 **인간-AI 간 협력적 성찰 역량 함양**을 목표로 연구·도출된 **13대 교육공학적 설계원리**를, 어포던스 설계 명세 v1에 따라 **화면(국면) 분리 구조**로 구현한 프로토타입입니다.

핵심 원칙: **“어디서 설정하고, 어디서 대화하고, 어디서 되짚는가”는 서로 다른 화면이어야 한다.** 설정과 성찰을 채팅창 안에서 처리하면 원리 2(선택권 보존)와 원리 11·12(성찰)의 효과가 대화 흐름에 묻혀 사라지기 때문입니다.

Upstage의 초거대 언어모델(**Solar Pro**)을 기반으로 구동되며, 대화 전 설정 → 대화 → 대화 직후 되짚기 → (지연) AI 없는 인지적 잔여물 확인까지 자기조절학습(SRL) 사이클 전 국면을 지원합니다.

### 화면(국면) 구조

| 국면 | 화면 | 채팅 UI | 담는 원리 |
| :--- | :--- | :--- | :--- |
| 진입·식별 | 닉네임 + 빠찡코형 4자리 그림 잠금(슬롯 돌리기·정지) | 아님 | (저연령 진입장벽 완화·게임화) |
| 설정(STEP 1–5) | 학교급·과목·성취기준 메타데이터 · 학습목표 · 역할분담 슬라이더 · 사전지식 자가점검 · 메타인지 3문항(이해/전략/연결) — **폼** | 아님 | 4·5·6·7 |
| 대화(STEP 6) | 전략 선택 칩 · 모든 AI 응답에 **수용/보류/코멘트** · 지원강도 배지(누적될수록 옅어짐) · **“나 지금 막혔어”** 점검 요청 · 자유 입력 상시 | 채팅 | 1·2·8·9·10 |
| 직후 성찰(STEP 7) | 턴별 **내 주도/AI 위임** 태깅 타임라인 · 질문 유형 비율 도넛 · 수용 분포 · 되짚기 서술 | 아님 | 3·11·12 |
| 잔여물 확인(STEP 8) | 지연 트리거 후 **AI 없는 별도 세션**. 근접·원거리 전이 2문항(시험지형) · 자기설명 필수 · 확신도 슬라이더 · **4축 근거 루브릭**(절차적 정확도만 규칙기반 객관 확인, 나머지는 근거만) · 전후 비교 · 델타 수용 여부는 학습자가 판단 | 아님 (AI 배제) | 1·2·13 |

브라우저 `localStorage`에 진행 상태를 저장하므로, 잔여물 확인 단계는 실제로 **나중에 이어서** 수행할 수 있습니다.

## 🔒 API 키 보안 안내 (중요)

이 시스템은 **API 키를 브라우저(index.html)에 절대 하드코딩하지 않습니다.** 대신:

1. **기본 동작(권장)**: 브라우저는 `/api/chat`이라는 자체 서버 프록시만 호출하고, 실제 Upstage API 키는 서버 환경변수(`UPSTAGE_API_KEY`)에만 보관됩니다. 이 방식은 Vercel처럼 서버리스 함수를 실행할 수 있는 호스팅에서만 동작합니다.
2. **개인 키 모드(선택)**: `/api/chat` 프록시가 없는 정적 호스팅(GitHub Pages 등)에서는 우측 상단 ⚙ 설정에서 학습자 본인의 Upstage API 키를 입력할 수 있습니다. 이 키는 **입력한 브라우저의 `localStorage`에만 저장**되며 절대 저장소(git)에 커밋되지 않습니다.

> [!WARNING]
> 과거 커밋에 테스트용 Upstage API 키가 실수로 하드코딩되어 공개 저장소에 노출된 적이 있습니다. 해당 키는 **Upstage 콘솔(https://console.upstage.ai/)에서 반드시 폐기·재발급**하시고, 새 키는 아래 방법대로 서버 환경변수 또는 `.env`(로컬 실행 시)에만 넣어주세요. 코드에 다시 하드코딩하지 마세요.

### Python(Streamlit) 로컬 실행용 `.env` 설정

```env
# Upstage 개발자 콘솔 (https://console.upstage.ai/)에서 발급받은 API 키
UPSTAGE_API_KEY=여기에_발급받으신_키를_붙여넣으세요

# 모델 설정 (기본: solar-pro)
UPSTAGE_MODEL=solar-pro
UPSTAGE_BASE_URL=https://api.upstage.ai/v1
UPSTAGE_REASONING_EFFORT=medium
```
> [!IMPORTANT]
> `.env` 파일은 `.gitignore`에 등록되어 있어 git에 커밋되지 않습니다. 소스 코드를 수정할 필요 없이 `.env` 값만 입력/변경하면 됩니다.

## ▲ Vercel 배포 (API 키 안전하게 보관하기, 권장)

`index.html` + `api/chat.js`(서버리스 프록시)를 함께 배포하면, 학습자는 아무 설정 없이 바로 사용할 수 있고 API 키는 서버에만 존재합니다.

```bash
# 1. Vercel 로그인 (최초 1회, 브라우저 인증)
vercel login

# 2. 프로젝트 루트에서 배포
vercel --prod

# 3. API 키를 Vercel 환경변수로 등록 (배포와 별개로 1회 설정)
vercel env add UPSTAGE_API_KEY production
# -> 프롬프트가 뜨면 Upstage 콘솔에서 발급받은 키 값을 입력

# 4. 환경변수 반영을 위해 재배포
vercel --prod
```

배포가 끝나면 `https://<프로젝트명>.vercel.app` 형태의 URL이 발급됩니다. 이 URL이 API 키가 노출되지 않는 **정식 서비스 주소**입니다.

## 🏛️ 13대 교육공학적 설계원리 매핑 (어포던스 v1)

| 계열 | 원리 | 화면 · 어포던스 |
| :--- | :--- | :--- |
| **시스템 공통** | **1. 비계의 적응적 지원 감소(Fading)** | 대화 화면 상단 **지원강도 배지**(높음→중간→낮음)가 색·게이지로 상시 노출. AI 응답을 연속 “수용”하면 자동으로 한 단계 낮아지며 알림 표시. “역할 조정”으로 언제든 수동 복귀 가능. 잔여물 확인 결과가 다음 세션 시작 강도에 반영 |
| | **2. 학습자 선택권 및 최종판단 보존** | 시스템 프롬프트에 “정답·이해도·수용 여부를 AI가 단정하지 말고 판단을 학습자에게 돌려줄 것”을 규칙으로 고정. 전략·역할·비계·수용여부·전후 델타 판단이 모두 학습자의 클릭/입력으로만 확정. 입력창은 항상 자유 텍스트 |
| | **3. 대화과정의 기록 및 시각화** | 전 과정 `localStorage` 저장. 되짚기 화면의 턴별 타임라인·질문유형 도넛·수용 분포 대시보드. 잔여물 확인의 4축 근거표 |
| **설정 (대화 준비)** | **4. 학습 목표 및 교과 맥락 설정** | STEP 1–2: 학교급·학년·과목 드롭다운 → 성취기준 메타데이터 칩 선택 → 목표 서술 폼(성취기준 기반 예시 추천 칩) |
| | **5. 학습자-AI 간 과업 분담 명확화** | STEP 3: “힌트만 ↔ 첨삭까지” 슬라이더로 AI 개입 강도를 학습자가 직접 설정(대화 중 재조정 가능) |
| | **6. 교과 내용지식 사전 활성화 및 점검** | STEP 4: 성취기준 연계 1~5 자가평가 슬라이더 + 사전지식 서술 문항 |
| | **7. 메타인지적 지식 점검** | STEP 5: 이해질문·전략질문·연결질문 3문항 폼(Kramarski & Mevarech) |
| **대화 (인지전략 조절)** | **8. 인지 전략 계획 수립** | 첫 AI 응답 하단 **전략 선택 칩**(사고구술/예시요청/반박요청/구조화/근거점검)을 학습자가 직접 고름 |
| | **9. 학습 과정 모니터링 기반 조정** | 입력창 옆 **“나 지금 막혔어”** 버튼 → AI가 점검 질문 1개 + 대안 전략 1~2개 제안, 최종 전략 변경은 학습자가 칩으로 선택 |
| | **10. AI 기반 응답 검증 및 수용 여부 판단** | 모든 AI 응답에 **수용 / 보류 / 코멘트** 버튼(자동 판정 없음). 코멘트는 인라인 입력. 수용 이력이 원리 1 자동 페이딩의 근거 |
| **직후 성찰 (대화 이후)** | **11. 학습자-AI 간 역할 및 위임 성찰** | 되짚기 화면의 가로 타임라인 — 각 턴을 눌러 **내 주도 / AI 위임** 태깅 + 주도/위임 비율 도넛 |
| | **12. 상호작용 및 질문 궤적 성찰** | 같은 화면의 질문유형 대시보드 + “다음엔 프롬프트를 어떻게 바꿀까” 서술 입력란 |
| | **13. 교과 지식 및 인지 전략 변화 성찰** | STEP 8: 지연 트리거 후 **AI 없는 별도 세션**. 구조 동일·소재만 바꾼 근접전이 + 다른 맥락의 원거리전이 2문항을 스스로 풀고 자기설명(필수)·확신도 제출 → 절차적 정확도(규칙기반)·자기설명 품질·전략 전이·메타인지 정확도 **4축 근거**를 제시하되 “향상 여부” 라벨은 붙이지 않고 학습자가 수용/보류/코멘트로 판단 |

## 🚀 실행 방법

### 방법 1: 원클릭 배치 파일 실행 (가장 추천)
프로젝트 폴더 내의 **`run_chatbot.bat`** 파일을 더블 클릭하면 자동으로 환경을 감지하여 웹 브라우저가 실행됩니다.

### 방법 2: 명령 프롬프트(CMD / PowerShell) 실행
```bash
# 1. 의존성 패키지 설치
pip install -r requirements.txt

# 2. 스트림릿 애플리케이션 실행
streamlit run app.py
```

실행 후 웹 브라우저에서 `http://localhost:8501`로 접속됩니다.
